짜증, 분노, 답답함을 아무에게도 보여 주지 않고 **와다다 쏟아낼 수 있는 앱**이에요.
쓰는 동안 구름이 그 감정을 꿀꺽꿀꺽 받아먹고, 다 쓰면 구름이 "후우~" 불어서 글을 **홀씨처럼 날려 보내요.**
쓴 글은 어디에도 저장되지 않아요. 서버, 로그인, 광고가 없고 완전히 오프라인으로 동작해요.

## 이런 앱이에요

### 1. 와다다 쏟아내기
- 하고 싶은 말을 아무렇게나 써요. 쓰는 동안 구름이 입을 "아~" 벌렸다가 냠 삼켜요.
- **빨리 칠수록 구름이 반응해요.** 차분하게 쓰면 조용히 받아먹고, 빨라지면 분홍빛으로 부풀어요. 연타하면 `> <` 하고 찡그리며 주변에 파동이 일어요. 하늘도 따뜻하게 물들어요.
- 많이 쓸수록 구름이 점점 빵빵해져요.
- 구름은 **타이핑 속도만** 봐요. 글의 내용이나 뜻은 전혀 읽지 않아요.

### 2. 훌훌 날려 보내기
**"훌훌 날리기"** 버튼을 톡 누르거나 구름을 꾹 누르면, 구름이 숨을 크게 들이쉬었다가 "후우~" 불어요. 날리는 방식은 설정에서 고를 수 있어요.

| 기본 홀씨 | 찢어서 홀씨 |
|---|---|
| 글자 하나하나가 홀씨처럼 퍼져서 하늘로 날아가요. | 글이 반투명한 **구름 종이**가 돼요. 손가락으로 그으면 **그은 모양 그대로** 찢어져요. 곡선, 지그재그, 대각선 모두 돼요. 긋는 속도에 맞춰 찢는 소리와 진동이 따라와요. 다 찢으면 조각들이 팔랑팔랑 날아가다 홀씨로 부서져요. |

다 날아가면 *"훌훌, 이제 보내줬어요."* 문구가 뜨고, 빈 화면으로 돌아와요.

### 3. 저절로 사라지기
위쪽 ⏱ 알약을 누르면 자동으로 사라질 때까지의 시간을 고를 수 있어요.

| 선택 | 동작 |
|---|---|
| **즉시** | 쓰는 동안 **먼저 쓴 글자부터 차례로** 스르륵 녹아 없어져요. |
| **3초 / 15초** | 입력을 멈추고 이 시간이 지나면 날아가요. 날아가기 직전에 "곧 훌훌 날아가요" 알림이 뜨고, 이때 다시 쓰거나 알약을 누르면 취소돼요. |
| **끄기** | 직접 날릴 때까지 그대로 둬요. |

### 그 밖에
- **효과음:** 꿀꺽, 후우~, 반짝, 종이 찢는 소리가 나요. 아이폰 무음 모드에서는 울리지 않고, 듣던 음악도 끊기지 않아요.
- **진동:** 끌 수 있어요.
- **애니메이션 강도:** "풍성하게"와 "은은하게" 중에 골라요. 처음에는 기기의 '동작 줄이기' 설정을 따라요.
- **첫 실행 안내:** 처음 켜면 카드 3장으로 사용법을 알려 줘요. 설정에서 다시 볼 수 있어요.

## 개인정보

이 앱이 **지키는 것**
- 쓴 글을 서버로 보내지 않아요. 애초에 서버가 없어요.
- 기록, 목록, 자동 저장이 없어요. 앱을 다시 켜도 이전 글은 남아 있지 않아요.
- 쓴 글을 로그나 오류 보고에 남기지 않고, 클립보드에 자동으로 복사하지도 않아요.
- 글이 날아가면 앱 메모리에서도 바로 지워요.
- 글이 화면에 있을 때 앱 전환 화면에서 내용을 가려요. iOS는 가림막을 띄우고, 안드로이드는 앱 전환 화면을 비우면서 스크린샷도 막아요.
- 마이크 권한을 요청하지 않아요.

이 앱이 **막을 수 없는 것**
- 키보드 앱(삼성 키보드, Gboard 등)이 자체적으로 입력을 학습하는 것
- 기기 백업
- 다른 기기로 화면을 촬영하는 것

설정 → 개인정보에도 같은 내용이 적혀 있어요.

## 다운로드

### 안드로이드
1. [**Releases**](https://github.com/jivvoow/void/releases/latest)에서 `hulhul-vX.Y.Z.apk`를 휴대폰으로 다운로드해요.
2. 파일을 열고 **"출처를 알 수 없는 앱 설치"를 허용**해요. 처음 한 번만 하면 돼요.
3. 설치하면 홈 화면에 구름 아이콘 **훌훌**이 생겨요.

> 스토어를 거치지 않은 앱이라 Play 프로텍트가 경고를 띄울 수 있어요.

### 아이폰
애플은 앱스토어 밖에서 설치 파일을 나눠 주는 걸 허용하지 않아서, GitHub로는 배포할 수 없어요.
대신 아래 [직접 실행하기](#직접-실행하기)대로 PC에서 띄운 다음, **Expo Go** 앱으로 QR 코드를 찍으면 열 수 있어요.

## 개발자용

### 직접 실행하기
```bash
npm install
npx expo start          # 터미널의 QR 코드를 Expo Go 앱으로 스캔
npm run typecheck       # TypeScript 검사
```
- 휴대폰과 PC가 같은 Wi‑Fi에 있어야 해요. 공용 와이파이처럼 안 되는 곳이면 `npx expo start --tunnel`을 쓰세요.
- Expo Go는 **SDK 58**을 지원하는 버전이어야 해요.
- 앱 이름, 아이콘, 스플래시는 Expo Go에서 보이지 않아요. 확인하려면 APK를 설치하세요. 안드로이드 화면 캡처 방지도 APK에서 확인하는 게 정확해요.

### 새 버전 배포
`v`로 시작하는 태그를 푸시하면 GitHub Actions가 동작해요. EAS 클라우드에서 APK를 빌드하고 Releases에 올려 줘요([`release-apk.yml`](.github/workflows/release-apk.yml)).

```bash
# app.json 의 "version" 을 올리고 커밋한 뒤
git tag v0.2.0
git push origin v0.2.0      # 10~30분 뒤 Releases 에 hulhul-v0.2.0.apk
```
**처음 한 번만** 해 둘 것
- `npx eas-cli@latest login`
- `npx eas-cli@latest init`
- [Expo 액세스 토큰](https://expo.dev/settings/access-tokens)을 만들어 저장소 Secrets에 `EXPO_TOKEN`으로 저장

- `expo-haptics` · `expo-audio` · `expo-screen-capture` · `expo-linear-gradient`

  - 한글 11,172자를 모두 담고 있어요. 그래서 "앜"처럼 입력 도중에만 잠깐 나타나는 글자도 다른 글꼴로 바뀌어 보이지 않아요.

### 설계 메모
- **한글 입력:** 입력창은 `value`를 넘기지 않는 비제어 `TextInput`이에요. 비울 때는 커밋이 끝난 뒤 `clear()`를 부르거나, `key`를 바꿔 입력창을 새로 만들어요. 그래서 iOS와 안드로이드 키보드의 한글 조합이 깨지지 않아요.
- **즉시 모드:** 실제 입력창의 글자는 투명하게 두고, 그 위에 같은 글을 겹쳐 그려요. 겹쳐 그린 글자만 하나씩 흐려져요. 실제 입력 내용은 건드리지 않아서 한글 조합에 영향이 없어요.
- **개인정보:** 원문은 `useRef` 하나와 네이티브 입력창에만 있어요. 날리는 연출 동안만 스냅샷을 잠깐 들고 있다가, 끝나면 바로 버려요.
- **날리기 타임라인:** 진행값 하나(`fadeProgress`, 0→1, 1.6초)가 구름 몸과 표정, 바람, 글자나 종이 조각, 홀씨를 모두 움직여요. 단계는 들숨(0–0.2) → 후우~(0.25–0.74) → 후련함 순서예요.
- **찢기:** 손가락 경로를 매끈하게 다듬은 뒤, 일정한 규칙으로 들쭉날쭉하게 만들어요. 종이 안에서 멈춘 선은 그 방향으로 가장자리까지 늘려요. 이 선으로 각 조각을 둘로 나눠요. 두 조각이 같은 가장자리를 공유하니까 퍼즐처럼 맞물려요. 각 조각은 같은 종이(그라데이션과 손글씨)를 SVG 클립으로 잘라 보여 줘요.
- **동작 줄이기:** Reanimated는 기기에서 '동작 줄이기'를 켜면 애니메이션을 끝으로 건너뛰어요. 그러면 날리는 연출이 한순간에 끝나 버려서, `ReducedMotionConfig`로 이 동작을 끄고 앱 설정의 '애니메이션 강도'로 조절해요.
- **에셋:** 아이콘, 스플래시, 효과음은 모두 이 저장소의 스크립트로 직접 만들었어요. 외부 샘플이나 이미지를 쓰지 않았어요.

## About

**훌훌**은 짜증, 분노, 답답함을 아무에게도 보여 주지 않고 **와다다 쏟아낼 수 있는 감정 배출 앱**이에요.
쓰는 동안 구름 캐릭터가 감정을 받아먹고, 다 쓰면 구름이 "후우~" 불어서 글을 **홀씨처럼 날려 보내요.**

- 서버, 로그인, 광고, 분석 도구가 없어요. 오프라인에서 동작해요.
- 쓴 글은 저장하지 않아요. 앱을 다시 열면 항상 빈 화면이에요.
- 글의 내용이나 뜻은 분석하지 않아요. 구름은 **타이핑 속도**에만 반응해요.
- React Native + Expo로 만든 네이티브 앱이에요. WebView 앱이 아니에요.

현재 앱 화면은 한국어로 제공돼요. 영어 문구 파일은 있지만, 설정의 영어 선택지는 아직 "준비 중"으로 비활성화되어 있어요.

## How It Works

```
 ① 쓰기                 ② 구름이 받아먹기               ③ 날려 보내기
 하고 싶은 말을    →    입력 속도에 따라 구름이    →    "훌훌 날리기" / 구름 꾹 / 자동 소멸
 아무렇게나 입력         입을 벌려 삼키고 부풀어요        → 구름이 "후우~" → 글이 홀씨처럼 날아감
                                                          → "훌훌, 이제 보내줬어요." → 빈 화면
```

1. **Write:** 입력 칸을 누르고 마음껏 써요. 한글 입력이 깨지지 않도록 만들었어요.
2. **Feed the cloud:** 쓰는 동안 구름이 입을 벌렸다 다물며 삼켜요. 빨리 쓸수록 더 크게 반응해요.
3. **Let it go:** 직접 날리거나, 정해 둔 시간이 지나면 저절로 날아가요. 다 날아가면 앱은 처음 상태로 돌아가요.

## Features

### Type It Out
- 쓰는 동안 구름이 입을 "아~" 벌렸다가 다물고, 한 번 오물거리며 삼켜요. 삼킬 때마다 몸이 납작해졌다 늘어나요.
- **타이핑 속도에 따라 3단계로 반응해요.** 최근 2초 동안의 초당 입력 이벤트 수로 판단해요.

  | 단계 | 기준 | 구름과 화면 |
  |---|---|---|
  | calm | 초당 4.5회 미만 | 깨어 있는 표정, 조용히 받아먹음 |
  | building | 4.5회 이상 | 분홍빛으로 부풀고, 주변에 파동, 하늘이 따뜻해짐, 가벼운 진동 |
  | burst | 7.5회 이상 | `> <` 찡그림, 화난 선, 더 강한 파동과 진동 |

- 많이 쓸수록 구름이 점점 빵빵해지고, 글을 지우면 다시 작아져요.
- 입력할 때마다 글자가 살짝 튀어요. 강도가 높을수록 더 크게 흔들려요.

### Let It Go
**"훌훌 날리기"** 버튼을 한 번 누르거나 구름을 0.8초 동안 꾹 누르면, 구름이 숨을 크게 들이쉬었다가 "O" 입으로 "후우~" 불어요. 입에서 바람 줄기와 반짝이가 뿜어져 나와요. 날리는 방식은 설정의 **날리는 방식**에서 고를 수 있어요.

| 기본 홀씨 | 찢어서 홀씨 |
|---|---|
| 글자 하나하나가 바람에 흩어져 홀씨처럼 위로 날아가요. 글자마다 작은 솜털이 붙어 있어요. | 글이 반투명한 **구름 종이**가 돼요. 손가락으로 그으면 **그은 모양 그대로** 찢어져요. 곡선, 지그재그, 대각선 모두 돼요. 종이 안에서 멈춘 선은 그 방향으로 가장자리까지 이어서 찢어지고, 최대 16조각까지 나뉘어요. 긋는 속도에 맞춰 찢는 소리와 진동이 따라와요. 손을 떼고 잠시 기다리거나 종이를 톡 누르면, 조각들이 팔랑이며 날아가다 홀씨로 부서져요. |

- 찢어서 홀씨에서는 이런 경우 앱이 대신 찢어 줘요.
  - 하나도 안 찢고 종이를 누르면, 두 번 찢은 뒤 날려요.
  - 7초 동안 찢지 않으면, 알아서 찢어서 날려요.
  - 자동 소멸 타이머로 끝날 때도, 알아서 찢어서 날려요.
- 다 날아가면 *"훌훌, 이제 보내줬어요."* 문구와 차임 소리가 나고, 빈 화면으로 돌아와요.

### Auto Fade
위쪽 ⏱ 알약이나 설정에서 자동 소멸 방식을 골라요. 기본값은 **15초**예요.

| 선택 | 동작 |
|---|---|
| **즉시** | 쓰는 동안 **먼저 쓴 글자부터 차례로** 스르륵 녹아 사라져요. 손을 멈추면 입력창이 조용히 비워지고, 키보드는 그대로 열려 있어요. 이 모드에는 "훌훌 날리기" 버튼이 없어요. |
| **3초 / 15초** | 입력을 멈추고 이 시간이 지나면 날아가요. 날아가기 직전에 "곧 훌훌 날아가요" 알림과 줄어드는 바가 나와요. 이때 다시 쓰거나 알약을 누르면 취소돼요. 15초는 마지막 5초, 3초는 시간의 60% 구간이 알림 구간이에요. |
| **끄기** | 직접 날릴 때까지 그대로 둬요. |

- 설정 화면을 열어 둔 동안에는 타이머가 멈춰요.
- 앱을 백그라운드로 보냈다가 돌아오면, 실제로 흐른 시간을 기준으로 다시 계산해요.

### Additional Features
- **효과음:** 꿀꺽, 후우~, 반짝, 차임, 종이 찢는 소리, 찢어지는 "쫙!"이 나요.
  - 아이폰 무음 스위치를 켜면 울리지 않아요.
  - 듣고 있던 음악과 함께 섞여서 나요.
  - 설정에서 끌 수 있어요.
- **진동:** 설정에서 끌 수 있어요.
- **애니메이션 강도:** "풍성하게"와 "은은하게" 중에 골라요. 처음에는 기기의 '동작 줄이기' 설정을 따라요.
- **첫 실행 안내:** 처음 켜면 카드 3장으로 사용법을 알려 줘요. 카드를 누르면 넘어가고, 설정의 "사용법 다시 보기"로 다시 볼 수 있어요.
- **키보드 내리기:** 빈 곳을 누르거나 오른쪽 위 ⌄ 버튼을 누르면 키보드가 내려가요. 쓴 글은 그대로 남아요.

## Privacy

앱이 **실제로 하는 것**만 적었어요.

- **서버와 계정이 없어요.** 쓴 글을 네트워크로 보내는 코드가 없고, 분석, 광고, 오류 수집 도구도 넣지 않았어요.
- **글을 저장하지 않아요.** 쓴 글은 화면에 있는 동안 앱 메모리와 입력창에만 있어요. 파일, 데이터베이스, 기록 목록, 자동 저장이 없어요.
  - 기기에 저장되는 건 **설정값뿐**이에요: 자동 소멸 시간, 날리는 방식, 진동, 효과음, 애니메이션 강도, 언어, 안내를 본 여부.
- **날아가거나 지우면 앱이 들고 있던 글을 비워요.** 입력창은 새로 만들어 이전 내용을 비워요. 날리는 연출에 쓰는 복사본도 연출이 끝나면 버려요.
  - 다만 이미 해제된 메모리를 운영체제나 JS 엔진이 언제 덮어쓰는지까지는 앱이 제어할 수 없어요.
- **글을 로그에 남기거나 클립보드에 자동으로 복사하지 않아요.**
- **앱 전환 화면에서 글을 가려요.**
  - iOS: 앱 전환 화면에 블러를 씌우고, 앱이 비활성 상태가 되면 가림막을 띄워요.
  - Android: 글이 화면에 있거나 날아가는 동안 `FLAG_SECURE`를 켜요. 그동안은 앱 전환 화면이 비고, 스크린샷과 화면 녹화도 막혀요.
  - iOS에서는 사용자가 직접 찍는 스크린샷은 막지 않아요.
- **마이크를 쓰지 않아요.** 오디오 라이브러리의 마이크 권한 설정을 꺼 두었고, 녹음 기능도 없어요.

**앱이 보장할 수 없는 것**
- 키보드 앱(삼성 키보드, Gboard 등)의 학습이나 예측 기능
- 운영체제 백업
- iOS 스크린샷
- 다른 기기로 화면을 촬영하는 것

이처럼 앱 바깥에서 남는 흔적은 앱이 지울 수 없어요. 앱 안의 설정 → 개인정보에도 같은 내용이 적혀 있어요.

## Getting Started

**필요한 것**
- Node.js와 npm
- 휴대폰에 설치한 [Expo Go](https://expo.dev/go) (SDK 58 지원 버전)

```bash
git clone https://github.com/jivvoow/void.git
cd void
npm install
npx expo start          # 터미널에 뜨는 QR 코드를 Expo Go 앱으로 스캔
npm run typecheck       # TypeScript 검사 (tsc --noEmit)
```

- 휴대폰과 PC가 같은 네트워크에 있어야 해요. 공용 와이파이처럼 기기끼리 연결이 막힌 곳에서는 `npx expo start --tunnel`을 쓰세요. 처음 실행할 때 `@expo/ngrok` 설치를 물어볼 수 있어요.
- Expo Go에서는 앱 이름, 아이콘, 스플래시 대신 Expo Go의 것이 보여요. Android 화면 캡처 방지 같은 앱 전환 보호도 실제 빌드(APK)에서 확인하는 게 정확해요.

| 항목 | Expo Go | 실제 빌드 (APK 등) |
|---|---|---|
| 메인 화면, 구름, 입력, 자동 소멸과 직접 날리기, 찢기 | ✅ | ✅ |
| Reanimated 애니메이션, SVG, 햅틱, 효과음 | ✅ | ✅ |
| 앱 전환 화면 보호 (iOS 블러, Android `FLAG_SECURE`) | ✅ (Expo Go 설정과 섞일 수 있음) | ✅ |
| 앱 이름 "훌훌", 아이콘, 스플래시 | ❌ | ✅ |

## Tech Stack

| 영역 | 사용 |
|---|---|
| 프레임워크 | React Native 0.88.1 · Expo SDK 58 · React 19.3 · TypeScript 6 |
| 애니메이션 | `react-native-reanimated` 4.7 + `react-native-worklets` (모든 애니메이션을 UI 스레드에서 실행) |
| 그래픽 | `react-native-svg` (구름 캐릭터, 찢어지는 종이), `expo-linear-gradient` (하늘) |
| 피드백 | `expo-haptics`, `expo-audio` |
| 개인정보 | `expo-screen-capture` (앱 전환 보호, `FLAG_SECURE`) |
| 저장 | `@react-native-async-storage/async-storage` (**설정값만**) |
| 폰트 | [Gamja Flower](https://fonts.google.com/specimen/Gamja+Flower) via `@expo-google-fonts/gamja-flower` (SIL OFL) |
| 빌드와 배포 | EAS Build, GitHub Actions |

- 감자꽃(Gamja Flower) 폰트는 한글 11,172자를 모두 담고 있어요. 그래서 "앜"처럼 입력 도중에만 잠깐 나타나는 글자도 다른 글꼴로 바뀌어 보이지 않아요.
- 화면 이동은 Expo Router를 쓰지 않았어요. 앱이 **한 화면** 안에서 상태로 전환되고, 설정은 Modal로 열려요.

## Release & Deployment

GitHub Actions 워크플로 [`release-apk.yml`](.github/workflows/release-apk.yml)은 `v`로 시작하는 태그가 푸시되면 이렇게 동작해요.

1. Node 22에서 `npm ci`를 실행해요.
2. `expo/expo-github-action`으로 EAS CLI를 준비해요.
3. `eas build --platform android --profile preview`로 EAS 클라우드에서 APK를 빌드하고, 빌드가 끝날 때까지 기다려요.
4. 빌드 결과물을 `hulhul-<태그>.apk`로 내려받아요.
5. 해당 태그의 GitHub Release를 만들고 APK를 첨부해요. 릴리스 노트와 설치 안내도 함께 넣어요.

**새 버전 내기**
```bash
# app.json 의 "version" 을 올리고 커밋한 뒤
git tag v0.2.0
git push origin v0.2.0
```
빌드에 걸리는 시간은 EAS 대기열 상황에 따라 달라요. 진행 상황은 저장소의 **Actions** 탭에서 확인할 수 있어요.

**필요한 설정**
- `app.json`의 `extra.eas.projectId`: 이 저장소는 이미 연결되어 있어요. 포크해서 쓰는 경우에는 `npx eas-cli@latest init`으로 자기 프로젝트에 연결하세요.
- 저장소 Secret **`EXPO_TOKEN`**: [Expo 액세스 토큰](https://expo.dev/settings/access-tokens)을 만들어 **Settings → Secrets and variables → Actions**에 등록해요.

**빌드 프로필** ([`eas.json`](eas.json))
- `preview`: 내부 배포용 Android **APK**. GitHub Release에 쓰는 프로필이에요.
- `production`: 스토어 제출용. 현재 워크플로에서는 쓰지 않아요.
- 빌드 번호는 EAS가 원격으로 관리하고 빌드마다 자동으로 올려요(`appVersionSource: remote`, `autoIncrement`).

**직접 빌드만 해 보기**
```bash
npx eas-cli@latest build -p android --profile preview   # 완료되면 APK 다운로드 링크가 나와요
```

## Technical Notes

- **한글 입력:** 입력창은 `value`를 넘기지 않는 비제어 `TextInput`이에요. 비울 때는 커밋이 끝난 뒤 `clear()`를 부르거나, `key`를 바꿔 입력창을 새로 만들어요. `onChangeText` 안에서 `clear()`를 부르면 네이티브가 무시해서, 커밋 뒤로 미뤄요. 이렇게 해서 iOS와 Android 키보드의 한글 조합이 깨지지 않아요.
- **즉시 모드:** 실제 입력창의 글자는 투명하게 두고 커서만 보여요. 그 위에 같은 글을 겹쳐 그리고, 글자마다 따로 흐려져요(0.45초 유지 → 1초 동안 흐려짐). 실제 입력 내용은 건드리지 않아서 한글 조합에 영향이 없어요. 즉시 모드와 다른 모드를 오갈 때는 입력창을 새로 만들어서, 투명 글자색이 남지 않게 해요.
- **개인정보:** 원문은 `useRef` 하나와 네이티브 입력창에만 있어요. 날리는 연출 동안만 스냅샷을 잠깐 들고 있다가, 끝나면 바로 버려요.
- **날리기 타임라인:** 진행값 하나(`fadeProgress`, 0→1, 1.6초)가 구름 몸과 표정, 바람, 글자나 종이 조각, 홀씨를 모두 움직여요. 단계는 들숨(0–0.2) → 후우~(0.25–0.74) → 후련함 순서예요. 모두 UI 스레드에서 계산해요.
- **찢기:** 손가락 경로를 일정 간격으로 다시 찍고, 정해진 규칙으로 들쭉날쭉하게 만들어요. 종이 안에서 멈춘 선은 그 방향으로 가장자리까지 늘려요. 이 선으로 각 조각(다각형)을 나누는데, 두 조각이 같은 가장자리를 공유하니까 퍼즐처럼 맞물려요. 각 조각은 같은 종이(그라데이션과 손글씨)를 SVG `ClipPath`로 잘라 보여 줘요. 손글씨 줄바꿈은 보이지 않는 `Text`의 `onTextLayout` 결과를 그대로 써요.
- **찢는 소리:** 반복 재생하는 찢는 소리를 손가락 속도에 맞춰 크기와 재생 속도를 바꿔요. 손가락이 약 0.1초 동안 움직이지 않으면 멈춰요. 한 번 찢어질 때마다 "쫙!" 소리가 따로 나요.
- **동작 줄이기:** Reanimated는 기기의 '동작 줄이기'가 켜져 있으면 애니메이션을 끝으로 건너뛰어요. 그러면 날리는 연출이 한순간에 끝나 버려서, `ReducedMotionConfig`(`ReduceMotion.Never`)로 이 동작을 끄고 앱 설정의 '애니메이션 강도'로 조절해요. 이 설정의 처음 값은 기기 설정을 따라요.
- **에셋:** 아이콘, 스플래시, 효과음은 모두 `scripts/`의 스크립트로 직접 만들었어요. 외부 샘플이나 이미지를 쓰지 않았어요.
